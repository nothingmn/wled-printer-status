Lights in the module

i
One screen per light, and nothing about printers on it. Everything here comes from the light itself — version, pixels, segments, presets — so the module never holds a copy that can drift. If a light dies and you replace the hardware, Replace this light moves every printer onto the new one.

Discovery is best effort — a light on another subnet, or a network that blocks multicast, will not answer. Adding by address is always there.
What is refused, and why
A light that does not answer when addedrefused at the door — not saved and left broken
Removing a light that carries a printeroffered, and it names exactly whose light goes away with it
Editing a segment's name or range herenot offered — segments belong to WLED, same as presets
Replacing a light with different hardwarerefused — the panel size and the pixel count must match
