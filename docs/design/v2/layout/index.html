Panela 2D matrix — rows × columns of pixels. morpheus is 256 × 64 = 16,384. Words and bars both fit.
Strip1D — one run of pixels, no rows. CyberDesk is 48 LEDs. A bar fits; a word cannot.
Either way, only a job in progress composes. Idle, finished, stopped and error keep the plain colour.
